# 🗄️ IKEA Inventory Management System | MySQL

A relational retail database and SQL analysis project to track stock, suppliers, stores and revenue growth.

---

## 📌 Project Overview
- Designed a database with **6 linked tables**: Customers, Products, Suppliers, Stores, Orders, Order_Details
- Used primary and foreign keys to connect the tables

## 🛠️ Tools & Concepts
MySQL · Joins · CTEs · Subqueries · CASE · Aggregate Functions · GROUP BY / HAVING · Window Functions (RANK, DENSE_RANK, LAG) · Date Functions

## ❓ Business Questions Solved
- Which stores, products and suppliers perform best?
- How does monthly revenue grow over time?
- Which products are low or out of stock?
- Which items are fast-moving and which are slow-moving?

## 💡 Key Insights
-  BangaloreStore generated the highest total revenue among all stores.
- A limited number of high-value (Platinum) customers contributed a significant portion of total revenue.
